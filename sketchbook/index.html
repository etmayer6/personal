How this stays friendly

Only these illustrated stickers and inks can be posted. The server picks a separate spot for each one—no drawing, uploads, names, or custom text.

Three stickers per guest pass each day, a minute apart. There is also a shared posting cap. This reduces abuse; it is not a promise of perfect moderation.

A guest pass is saved in this browser. The album is public. Removing your sticker leaves its spot blank and does not reset the posting limit.
